# NetBox scripts

A few small scripts I use to save time in NetBox. Nothing fancy, just things that were too boring to do by hand.
Some vibecoded.

- **NETBOX SCRIPT add device description to custom field IPAM**: copies a device's description onto its IP addresses.
- **NETBOX update front and rear port labels**: sets port labels in bulk from a CSV.
- **NETBOX update vlan interface from arista switches**: imports interfaces and IPs exported from Arista CVP.
- **NETBOX create a connection**: a CSV template for creating cables in bulk.

Each folder has its own README with the details.
